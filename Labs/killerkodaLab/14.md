# The problem is kubeapiserver is failing, and the connection is getting refused.
- k get nodes
- k get pods

- crictl ps -a | grep apiserver 
- crictl logs 56af72a13b5a2
you can see the kubeapiserver is trying to connect to the port 2380, but that port is for etcd to etcd connection,
apiserver to etcd is connected using 2379.
Port 2379: Client API - Used by kube-apiserver, kubectl, etcdctl
so change the port in the kubeapiserver.yaml static manifest file to 2379 and wait for 1-2min, the problem will be resolved
- k get nodes works.
