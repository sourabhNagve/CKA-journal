### exam-question.md

# 1. Exam Scenario

Task:
A deployment for the `billing-app` in the `finance` namespace needs to be deployed using Kustomize. The directory structure is prepared at `/opt/kustomize/billing`, containing a `base` and a `prod` overlay. 

A junior engineer attempted to deploy the `prod` overlay using `kubectl apply -k /opt/kustomize/billing/overlays/prod`, but encountered multiple errors. 

Your task is to fix the Kustomize overlay and successfully deploy the application.

Requirements:
1. Fix the invalid resource path in the `prod` overlay's `kustomization.yaml`.
2. Fix the JSON patch `replica-patch.yaml` which is failing to apply. It must scale the deployment to 3 replicas.
3. The `prod` overlay MUST override the deployment image to use `nginx:1.26.0`. You must achieve this using Kustomize's native image override feature in the `prod` overlay's `kustomization.yaml`.
4. The deployment expects a ConfigMap named `billing-config` to exist. Use Kustomize's `configMapGenerator` in the `prod` overlay to create this ConfigMap from the existing `/opt/kustomize/billing/overlays/prod/prod.env` file.
5. Successfully apply the `prod` overlay to the cluster.
6. The pods must reach the `Running` state.

# 2. Initial Cluster State

- **Namespaces**: `finance`
- **Kustomize Path**: `/opt/kustomize/billing`
  - `/opt/kustomize/billing/base` (Contains Deployment, Service, base kustomization)
  - `/opt/kustomize/billing/overlays/prod` (Contains broken prod kustomization)
